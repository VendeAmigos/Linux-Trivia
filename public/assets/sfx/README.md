# Efectos de Sonido (SFX)

Coloca aquí los archivos de audio para efectos de sonido adicionales:
- `attack.mp3` o `attack.wav` (Ataque del jugador)
- `hit.mp3` o `hit.wav` (Daño al enemigo)
- `correct.mp3` o `correct.wav` (Respuesta correcta)
- `wrong.mp3` o `wrong.wav` (Respuesta incorrecta)
- `click.mp3` o `click.wav` (Clics de interfaz)
- `victory.mp3` o `victory.wav` (Fanfarria de victoria)
